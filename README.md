# Paradigmas-Programacion

## Programación Imperativa

Este proyecto presenta un ejemplo sencillo de programación imperativa mediante un algoritmo de ordenamiento.

El programa utiliza el método de ordenamiento burbuja para organizar un grupo de números de menor a mayor.

## Conceptos utilizados

- Variables
- Arreglos
- Ciclos `for`
- Condicionales `if`
- Intercambio de valores
- Instrucciones secuenciales

## Lenguaje

Java

## Funcionamiento

El programa muestra los números antes de ordenarlos y luego los organiza de menor a mayor mediante el algoritmo de ordenamiento burbuja.
